# About

Baltazar Dental Appointment System is a web-based appointment management platform developed for **Baltazar Dental Clinic**. It allows patients to book appointments online while providing administrators with a centralized dashboard for reviewing, approving, rescheduling, and managing appointment requests.

The project was designed to improve the clinic's daily workflow by reducing manual scheduling, organizing patient appointments, and providing a more convenient booking experience.

As part of this project, I applied modern Laravel development practices, secure application design, and responsive user interface principles while working with real client requirements.

---

# Why I Built It

This project was developed as a client solution to modernize the clinic's appointment process.

My objectives during development were to:

* Build a secure Laravel web application.
* Improve appointment management workflows.
* Design an intuitive booking experience for patients.
* Create an organized administration dashboard.
